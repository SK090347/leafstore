leafstore

On-disk B+ tree key-value store in TypeScript. Fixed-size pages, put/get/ordered range, and single-file persistence — reopen the file and the keys are still there. Pair it with lumen-kv if you want the LSM side of the textbook too.

View on GitHub README

Pages & freelist

Header page tracks root, freelist, and page count. Leaves split ~halfway; internals fence children with separators.

Ordered range

In-order leaf walk over opaque byte keys with lexicographic [start, end) scans.

4096-byte pages

Packed leaf/internal layouts designed to teach real storage-engine page packing.

How to run

npm install && npm test && npm run build

import { LeafStore } from "leafstore";
const db = LeafStore.create("./demo.db");
db.put("alpha", "one");
console.log(db.getString("alpha")); // "one"
db.close();
